# Quy ước đặt tên file

## Mẫu chung

`YYYYMMDD-kh-nhom-chu-de-kenh-kich-thuoc-vNN-trang-thai.ext`

| Thành phần | Quy tắc |
| --- | --- |
| YYYYMMDD | Ngày tạo công việc, ví dụ 20261025; giữ nguyên khi tăng phiên bản |
| kh | Mã thương hiệu Kiên Hương |
| nhom | thuong-hieu, dich-vu, quang-cao-xe, khuyen-mai, su-kien, hinh-anh, noi-dung, mau |
| chu-de | Chủ đề ngắn; quảng cáo xe thêm dòng xe, dung tích/phiên bản nếu cần |
| kenh | facebook, avatar, story, dien-thoai, in-an, noi-bo |
| kich-thuoc | 1080x1350, 1080x1080; file in dùng 2000x3000mm; văn bản dùng na |
| vNN | v01, v02…; tăng khi sửa, không dùng final-final |
| trang-thai | nhap, cho-duyet, duyet, het-hieu-luc |
| ext | Đuôi đúng định dạng thực tế: png, jpg, svg, pdf, psd, ai, md… |

- Tên file/thư mục: chữ thường không dấu, số và dấu gạch ngang; không dùng khoảng trắng.
- Nội dung văn bản bên trong file vẫn viết tiếng Việt có dấu.
- Kích thước luôn theo chiều rộng × chiều cao. Tỷ lệ 3:4 có thể dùng 1080x1440.
- File nguồn và file xuất cùng nội dung dùng chung phần tên trước đuôi file.
- Biến thể dùng chủ đề phân biệt như `logo-kh-nen-do`, `logo-kh-trong-suot`, `sh160-den`.
- Không ghi trạng thái duyệt khi chưa có xác nhận; đổi tên không thay thế việc ghi nhận duyệt trong hồ sơ.

## Ví dụ minh họa

- `20261025-kh-thuong-hieu-logo-kh-nen-do-avatar-1080x1080-v01-nhap.png`
- `20261025-kh-dich-vu-bao-duong-facebook-1080x1350-v01-cho-duyet.png`
- `20261025-kh-quang-cao-xe-sh160-den-facebook-1080x1440-v02-nhap.jpg`
- `20261025-kh-su-kien-ban-giao-xe-in-an-2000x3000mm-v01-nhap.pdf`
- `20261025-kh-noi-dung-moi-mua-xe-facebook-na-v01-nhap.md`

Các tên trên là ví dụ, chưa có file thiết kế tương ứng.

## Thư mục công việc và lưu trữ

Dùng `YYYYMMDD-chu-de/` trong nhóm phù hợp; thêm `sources/`, `working/`, `exports/` khi có nội dung.
Nếu một chiến dịch có nhiều nhóm tài sản, ghi cùng mã chiến dịch trong hồ sơ và liên kết các đường dẫn liên quan, tránh sao chép nhiều bản gốc.
Khi chuyển vào `archive/YYYY/`, giữ cấu trúc nhóm/công việc, cập nhật đường dẫn trong danh mục.
